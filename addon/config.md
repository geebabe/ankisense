# AI Vocabulary Importer Configuration

- `llm_base_url`: Base URL for an OpenAI-compatible API endpoint (e.g. `https://api.openai.com/v1` or `https://api.deepseek.com/v1`).
- `llm_model`: Chat completion model identifier (e.g. `gpt-4o-mini` or `deepseek-chat`).
- `default_deck`: Default destination Anki deck name.
- `default_tts_locale`: Default Anki native TTS locale (`en_US`, `en_GB`, or `en_AU`).
- API keys (`llm_api_key`, `pexels_api_key`, `pixabay_api_key`) are stored in the macOS Keychain under service `anki-ai-vocab-importer` via the in-app **API Keys & Settings...** dialog.
